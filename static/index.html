🔑 Вход в SverkAI

Зачем личный API-ключ?
С личным ключом Anthropic: история сверок сохраняется, запросы идут с вашего аккаунта, нет ограничений на AI-анализ.
Без ключа: гостевой режим — история не сохраняется, используется общий API.
🔑 Личный API-ключ
История сохраняется. Используется ваш Anthropic API.
👤 Гостевой режим
Без сохранения истории. Работает на общем API.
Получить ключ: console.anthropic.com  •  Ключ хранится только в вашем браузере (localStorage)
