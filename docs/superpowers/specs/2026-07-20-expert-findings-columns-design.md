# Таблица выводов экспертного анализа

## Назначение

Сделать выводы Claude короче и однозначнее: пользователь сначала видит исходный документ, затем финансовое влияние и пояснение модели.

## Состав строки

- `Документ` — только точное название операции/документа из `resolved_evidence.document`. Для пары источников названия выводятся через ` ↔ `. Дубли удаляются. Если источник не удалось связать со строкой акта, выводится `Документ не определён`.
- `Влияние` — существующее числовое влияние расхождения с текущим цветовым оформлением.
- `Пояснение` — заголовок и обоснование Claude, а также предупреждение о ненайденном источнике, если оно есть.

Группировка по стандартизированному типу и порядок критичности сохраняются. Изменение применяется только к блоку экспертного анализа на вкладке «Сводка» и не меняет программные таблицы.

## Состояния

- Один источник: одно название документа.
- Два источника: оба названия через ` ↔ `.
- Повторяющийся источник: название показывается один раз.
- Нет связанного источника: понятная заглушка без выдуманного названия.
